# Codex Pond v0.1.0-preview.1

## 简体中文

这是 Codex Pond 的首个 Windows x64 便携预览版，包含原创像素池塘、六套场景、20 种鱼、四季与昼夜表现、鱼册，以及可独立游玩的钓鱼模式。源码中提供 Codex App Server、DeepSeek Harness headless 与 Work Buddy 连接器实现。

此版本仍属于早期预览。自动烟测使用假 Agent/MCP/Steam 事件流；真实 Agent 任务、用户授权、多屏 DPI/透明穿透以及 Steam 成就/云存档未完成端到端验收。Steamworks 原生 redistributable 未捆绑。Windows x64 可执行文件未签名。

## English

The first Windows x64 portable preview of Codex Pond. It includes original pixel-art pond scenes, six themes, 20 fish, seasonal and time-of-day ambience, a fish book, and standalone fishing. The source includes connectors for Codex App Server, DeepSeek Harness headless CLI, and Work Buddy.

This is an early preview. Automated smoke coverage uses fake Agent/MCP/Steam event streams. Real Agent tasks and approvals, multi-monitor DPI and transparent click-through, and Steam achievements/cloud saves have not completed end-to-end acceptance. The Steamworks native redistributable is not bundled. The Windows x64 executable is unsigned.
